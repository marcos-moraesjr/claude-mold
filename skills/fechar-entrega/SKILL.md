# Fechar entrega

- [ ] Testes escritos antes e passando.
- [ ] Checagens do projeto verdes. Entrega intermediária: só as rápidas, e diga que a completa ficou pendente.
- [ ] Interface alterada: requisitos de UI declarados pelo projeto.
- [ ] Strings e números mágicos checados (skill `commit`).
- [ ] Documentação e dívidas registradas.
- [ ] Nada fora do pedido.

Item não cumprido ou pulado: diga qual. Termine em "pronto para validação manual" e pare.

Se o projeto tiver `.claude/complementos/fechar-entrega.md`, leia e siga: ele detalha esta skill e vence em caso de conflito.

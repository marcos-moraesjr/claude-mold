
# Escrita de documentação

- Direta, no presente. Uma ideia por frase, até 25 palavras.
- Documente regra, estado e motivo; não repita o que o código diz.
- Uma fonte por fato. Sem histórico: isso fica no git.
- Documento até 200 linhas; parágrafo até 400 caracteres; títulos até `###`; tabela até 4 colunas.
- Preserve numeração de seção citada no código.
